# Wordly Dictionary SPA

## Description

Wordly is a single-page interactive dictionary application built with HTML, CSS, and JavaScript (JS). It allows users to search for English words and view definitions, pronunciation, examples, and synonyms when available.

## Features

1. Search for English words.
2. Display definitions and parts of speech.
3. Show pronunciation and play audio when available.
4. Display examples and synonyms when provided.
5. Save and remove favorite words.
6. Store favorites in browser local storage.
7. Switch between light and dark themes.
8. Display error messages for missing words and failed requests.

## Technologies Used

a. HTML5
b. CSS3
c. JavaScript
d. Fetch API and async/await
e. Free Dictionary API

## API

https://dictionaryapi.dev/

## How to Run

1. Download or clone the project.
2. Open the project folder in a code editor.
3. Open `index.html` using Live Server.
4. Enter a word in the search field and click Search.

## Project Files

- `index.html` — page structure.
- `style.css` — page styling.
- `index.js` — API requests, displaying results, favorites, and theme switching.
